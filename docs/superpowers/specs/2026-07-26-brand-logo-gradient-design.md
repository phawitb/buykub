# Brand logo gradient design

All primary Framelink wordmarks use one shared component. `FRAME` inherits the surrounding foreground color, while `LINK` uses a left-to-right text gradient from `#2563EB` to `#4F46E5`.

The typography, letter spacing, link targets, sizes, and accessible wordmark text remain unchanged. The shared component is used by the marketing navbar, login page, dashboard sidebar, legal pages, and footer.
